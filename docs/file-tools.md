# 파일 비교 및 작성 이력 도구

## 내장 화면

변경 파일 하나를 선택한 뒤 위쪽 **파일 도구** 메뉴에서 비교나 행별 이력을 엽니다. **선택 파일 비교 (Diff)**와 **선택 파일의 행별 이력 (Blame)**은 설정한 도구를 사용합니다. 내장 화면을 사용하려면 **내장 도구로 열기 → 선택 파일 비교 / 선택 파일의 행별 이력**을 선택하세요. 변경 목록에 없는 파일은 **다른 파일을 골라 비교…** 또는 **다른 파일의 행별 이력…**에서 고를 수 있습니다. 오른쪽 미리 보기의 **커밋할 내용** 체크는 Git에서만 제공되며, 체크 여부는 별도 비교 창에도 적용됩니다.

좌우 diff는 줄 번호와 변경 배경색, 이전·다음 변경 구간 이동, 내용 검색을 제공합니다. 긴 줄의 전체 내용은 **이전 내용 / 현재 내용** 탭에서 가로 스크롤하거나 복사할 수 있습니다. **통합 diff** 탭과 **패치 저장**으로 CLI의 원본 패치를 확인·저장합니다. 변경량이 매우 크면 일부 구간을 통째로 교체하는 블록으로 표시하며, 화면 아래에 이를 알립니다. 줄바꿈 형식과 마지막 줄바꿈 유무도 표시합니다.

Blame은 작업 중인 변경을 제외한 기준 리비전의 작성자·날짜·리비전·내용을 줄별로 보여줍니다. 작성자나 내용, 리비전으로 검색하고 **이력 저장**으로 TSV를 내보낼 수 있습니다. 축약된 리비전이나 날짜에 마우스를 올리면 원래 값을 확인할 수 있습니다. 제공자별 기준과 텍스트 제한은 [VCS 지원 범위](supported-vcs.md#파일-비교와-blame)를 참고하세요.

Lore의 내장 좌우 비교와 Blame에는 Lore 0.13.0 이상이 필요합니다. 좌우 비교는 현재 커밋과 디스크의 작업 파일을 비교하므로 스테이지한 변경도 오른쪽에 포함됩니다. 새 파일은 빈 이전 내용과, 삭제한 파일은 빈 현재 내용과 비교합니다. Blame은 현재 커밋에 있는 줄만 표시하며, 작성자는 리비전에 저장된 identity입니다. 조회할 수 없는 과거 이력은 원인을 표시하고 작성자를 추측하지 않습니다. 다른 연결 저장소에서 유래한 줄은 리비전을 표시하지만 작성자 조회는 지원하지 않습니다. 같은 결과를 외부 도구의 `{left}`·`{right}`·`{blame}` 인수로도 전달할 수 있습니다.

## 충돌 해결

Git·SVN에서 충돌로 표시된 파일을 선택하고 **파일 도구 → 선택 파일의 충돌 해결…**을 엽니다. 충돌 파일에 내장 Diff를 실행해도 충돌 해결 화면을 엽니다. 탐색기 파일 메뉴의 **차이 비교 (Diff)**도 내장 도구를 사용하는 경우 같은 흐름으로 연결됩니다. 외부 Diff를 설정했어도 **선택 파일의 충돌 해결…**은 내장 편집기를 엽니다.

1. 양쪽 내용과 공통 기준본을 확인합니다. Git의 양쪽은 index stage 2와 3입니다. 특히 rebase 중에는 stage 2가 적용 대상, stage 3이 적용 중인 변경이므로 단순히 ‘내 것/상대 것’으로 해석하면 안 됩니다.
2. 충돌 구간을 선택하고 **왼쪽 적용 / 오른쪽 적용 / 양쪽 이어 붙이기**를 누릅니다. 선택한 충돌 구간만 바뀌며, 결과를 직접 편집할 수도 있습니다. 양쪽 이어 붙이기는 의미나 중복을 판단하지 않으므로 내용을 검토하세요.
3. **해결 내용 저장**으로 작업 파일에 저장합니다. 진행 중인 편집을 저장해도 VCS의 충돌 상태는 그대로 유지됩니다.
4. 모든 충돌 표식을 제거하고 저장한 뒤 **해결 완료 표시**를 누릅니다. Git은 선택 파일만 `git add`하고, SVN은 `svn resolve --accept working --depth empty`로 작업 내용을 유지하며 충돌을 해제합니다. 다른 파일의 검토와 커밋은 별도로 진행합니다. rebase나 cherry-pick의 이어하기도 해당 VCS 도구에서 별도로 진행합니다.

편집기 지원 범위는 1 MiB 이하의 일반 UTF-8 텍스트 파일입니다. UTF-8 BOM과 기존의 단일 줄바꿈 방식(LF/CRLF/CR)을 유지합니다. 바이너리, 혼합 줄바꿈, 링크·서브모듈, 삭제·트리 충돌, SVN 속성 충돌은 내장 해결 대상이 아닙니다. Git의 양쪽 일반 파일이 있는 내용 충돌과 add/add 충돌, SVN의 기준·내 변경·받은 변경 스냅샷이 제공되는 텍스트 충돌을 지원합니다. 창을 연 뒤 작업 파일이나 충돌 정보가 바뀌면 덮어쓰지 않고 다시 열도록 안내합니다.

Git의 사용자 지정 `conflict-marker-size`는 7자 이상만 지원합니다. 더 짧거나 올바르지 않은 값은 충돌 표식을 놓치지 않도록 편집을 거부합니다.

저장 직전의 파일은 `%LOCALAPPDATA%\MoaVcs\ConflictBackups` 아래에 백업합니다. 이 위치로 이동할 수 없으면 원본과 같은 폴더의 `.moavcs-merge-*.bak`를 유지합니다. 저장 완료 안내에 마우스를 올리면 실제 백업 경로를 확인할 수 있습니다.

Lore와 Perforce는 충돌 정보를 읽고 해결을 완료하는 방식이 달라 내장 충돌 편집을 지원하지 않습니다. 전용 VCS 도구를 사용하세요. 일반 좌우 비교·Blame 지원은 그대로 유지됩니다. Git은 실제 로컬 병합 충돌로 검증하고, SVN은 공식 XML과 명령의 fixture로 검증합니다.

SVN 충돌 자료 형식은 [Apache Subversion의 info XML 출력](https://github.com/apache/subversion/blob/trunk/subversion/svn/info-cmd.c)을 기준으로 하며, 해결 완료는 [SVN resolve의 working 선택](https://svnbook.red-bean.com/en/1.8/svn.ref.svn.c.resolve.html)을 사용합니다.

## 외부 도구 설정

파일 우클릭의 **MoaVCS → 차이 비교 (Diff) / 행별 이력 (Blame)**도 설정한 도구로 열립니다. 기존 설치에서 새 Blame 메뉴를 보려면 **설정 → 탐색기 메뉴 → 메뉴 등록 / 갱신**을 한 번 실행하세요. 파일 경로를 지정한 `--action diff`와 `--action blame` 실행도 지원합니다.

앱 왼쪽 아래 **설정 → 비교·이력 도구**에서 차이 보기와 작성 이력 보기에 사용할 외부 프로그램을 선택할 수 있습니다. 기본 설정은 MoaVCS 내장 화면입니다. 외부 프로그램을 사용하려면 **외부 도구 사용**을 켜고 실행 파일을 지정하세요. 인수 템플릿은 접혀 있는 **고급 인수 설정**을 펼쳐 입력합니다. VCS 실행 파일 경로는 **설정 → 버전 관리 도구**에서 지정합니다.

인수 입력란은 줄마다 프로그램에 전달할 인수 하나를 나타냅니다. 공백이 포함된 경로도 인수 하나로 전달됩니다. 명령 문자열을 셸로 실행하지 않으며 `&`, 따옴표, 괄호 같은 문자를 셸 문법으로 처리하지 않습니다.

## 사용할 수 있는 자리표시자

| 도구 | 자리표시자 | 전달되는 값 |
| --- | --- | --- |
| 차이 보기 | `{left}` | 이전 파일 내용의 UTF-8 임시 스냅샷 경로 |
| 차이 보기 | `{right}` | 현재 파일 내용의 UTF-8 임시 스냅샷 경로 |
| 차이 보기 | `{patch}` | 통합 패치의 UTF-8 임시 파일 경로 |
| 작성 이력 보기 | `{blame}` | 파일 작성 이력의 UTF-8 TSV 임시 파일 경로 |
| 공통 | `{file}` | 저장소 안의 원본 파일 절대 경로 |
| 공통 | `{repo}` | 저장소 루트의 절대 경로 |

차이 보기 인수에는 `{left}`와 `{right}`를 함께 넣거나 `{patch}`를 넣어야 합니다. 작성 이력 보기 인수에는 `{blame}` 또는 `{file}`을 넣어야 합니다. `{file}`은 원본 파일을 직접 받는 외부 작성 이력 도구에 사용할 수 있습니다. 해당 프로그램의 인수 문법과 옵션은 프로그램 설명서를 확인하세요.

`{blame}` 파일은 탭으로 구분된 UTF-8 TSV입니다. 첫 행의 열 이름은 `Line`, `Revision`, `Author`, `Date`, `Text`입니다. 셀 안의 탭은 공백 네 칸으로, 줄바꿈은 공백으로 바꿉니다.

예를 들어 비교 프로그램이 두 파일 경로를 인수로 받는다면 입력은 다음처럼 구성합니다.

```text
{left}
{right}
```

패치 파일 하나를 받는 프로그램에는 다음 인수 하나를 사용합니다.

```text
{patch}
```

설정 파일에는 `ExternalTools` 아래 `Diff`와 `Blame` 항목으로 저장됩니다. 설정 창에서 입력하는 방식을 권장합니다.

```json
{
  "ExternalTools": {
    "Diff": {
      "UseExternal": true,
      "ExecutablePath": "C:\\Tools\\DiffTool.exe",
      "ArgumentTemplates": ["{left}", "{right}"]
    },
    "Blame": {
      "UseExternal": false,
      "ExecutablePath": "",
      "ArgumentTemplates": []
    }
  }
}
```

비교와 작성 이력 내용은 외부 프로그램이 읽을 수 있도록 `%LOCALAPPDATA%\MoaVcs\snapshots` 아래 임시 복사본으로 저장됩니다. 복사본을 편집해도 작업 트리에 반영되지 않습니다. MoaVCS는 시작할 때 7일보다 오래된 자체 스냅샷 폴더 중 일반 파일만 들어 있는 폴더를 정리합니다. 하위 폴더나 링크가 있는 폴더는 자동 삭제 대상에서 제외합니다. 보관할 내용은 다른 폴더에 저장하세요.
