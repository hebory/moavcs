# Windows 탐색기 메뉴와 상태 배지

앱은 셸 메뉴를 자동 등록하지 않습니다. 왼쪽 아래 **설정 → 탐색기** 탭에서 **메뉴 등록 / 갱신** 또는 **메뉴 제거**를 선택하거나, 앱 시작 인수로 명시할 수 있습니다.

우클릭 메뉴는 현재 사용자의 HKEY_CURRENT_USER\Software\Classes 아래 정적 메뉴 키만 사용합니다. 파일·폴더 상태 배지는 별도의 선택 설치 COM 확장을 사용합니다. [TortoiseGit의 메뉴 설정 방식](https://tortoisegit.org/docs/tortoisegit/tgit-dug-settings.html)을 참고해 자주 쓰는 작업은 탐색기 첫 메뉴에, 나머지는 **MoaVCS** 하위 메뉴에 배치했습니다. 파일 또는 폴더 하나를 선택했을 때 사용합니다.

## 파일·폴더 상태 배지 (v0.9.0)

**설정 → 탐색기 → 파일·폴더 상태 배지 → 상태 배지 켜기**로 활성화합니다. 최초 활성화는 Windows x64 셸 확장을 설치하므로 관리자 승인이 필요합니다. 설정 창을 열거나 일반 설정을 저장하는 것만으로 설치하지 않습니다. 기존 탐색기가 새 확장을 불러오려면 로그아웃 후 다시 로그인해야 할 수 있습니다. 사용 중인 DLL을 재설치한 경우에는 Windows를 다시 시작해야 할 수 있습니다. 앱이 탐색기를 강제로 종료하지는 않습니다.

| 배지 | 의미 |
|---|---|
| 빨간 느낌표 | 충돌 |
| 주황 연필 | 수정됨, 추가·삭제·이름 변경·스테이지된 변경 |
| 파란 물음표 | 추적 안 됨 / SVN unversioned |

폴더에는 하위 변경 중 **충돌 → 수정됨 → 추적 안 됨** 순으로 한 가지 배지를 표시합니다. 정상·무시 파일에는 배지를 붙이지 않으며, VCS 내부 폴더는 제외합니다. 삭제된 파일은 상위 폴더에 반영됩니다.

MoaVCS에서 열어 최근 목록에 저장한 **로컬 고정 드라이브 저장소 최대 12개**를 확인합니다. 네트워크·이동식 드라이브와 아직 앱에서 열지 않은 저장소는 제외합니다. Git·SVN·Perforce·Lore의 기존 상태 어댑터를 사용하며 제공자가 보고한 상태만 표시합니다. CLI가 없거나 실패·시간 초과하면 해당 저장소의 배지를 지웁니다. Perforce·Lore의 충돌 식별 등은 해당 CLI와 어댑터가 제공하는 정보에 따릅니다.

앱을 닫아도 사용자별 상태 확인 프로세스가 실행되며 로그인 때 시작합니다. 작업 후 보통 수초에서 수십 초 안에 갱신합니다. 대규모 저장소는 더 늦거나 20초 조회 제한으로 배지가 생략될 수 있습니다. 원격 Push·Pull·커밋이나 사용자 파일 수정은 실행하지 않습니다. 상태 배지를 끄면 현재 설치본의 시작 항목과 캐시를 제거합니다.

Windows는 시스템 전체에 최대 15개 오버레이 슬롯을 제공하고 일부를 자체 사용합니다. 다른 확장이 많으면 **MoaVCS 배지를 먼저 표시**를 선택한 뒤 켜세요. 이 옵션은 MoaVCS의 세 등록 이름만 앞순위로 바꾸며 다른 앱의 등록을 삭제하지 않습니다. 대신 일부 다른 앱 배지가 보이지 않을 수 있습니다. 표시 순서는 이 PC의 모든 사용자에게 적용됩니다. 바꾸려면 배지를 끄고 옵션을 변경한 뒤 다시 켭니다.

캐시는 `%LOCALAPPDATA%\MoaVcs\overlays\status.bin`, 최근 조회 오류는 같은 폴더의 `status.json`에 저장합니다. 탐색기 안의 네이티브 DLL은 캐시만 읽으며 VCS나 네트워크 명령을 실행하지 않습니다. 90초가 지난 캐시는 무효로 처리하고, 탐색기에 오래된 화면이 남으면 F5로 새로 고침합니다. 업데이트는 작업자를 먼저 종료한 뒤 다시 시작합니다. 앱 제거는 사용자별 작업자를 정리하지만 다른 사용자도 사용하는 셸 확장은 남깁니다. 확장 자체를 제거하려면 Windows 설치된 앱의 **MoaVCS 탐색기 상태 배지**를 제거하세요.

기술 기준: [Microsoft 오버레이 구현](https://learn.microsoft.com/en-us/windows/win32/shell/how-to-implement-icon-overlay-handlers), [시스템 전체 오버레이 등록](https://learn.microsoft.com/en-us/windows/win32/shell/how-to-register-icon-overlay-handlers).

## 메뉴 구성

기본 구성은 다음과 같습니다. 복제·생성은 별도의 ‘저장소’ 메뉴를 거치지 않고 바로 선택합니다.

| 위치 / 그룹 | 폴더 및 폴더 배경 | 파일 |
|---|---|---|
| 탐색기 첫 메뉴 | MoaVCS 업데이트 / Pull…, MoaVCS 커밋… | MoaVCS 커밋… |
| MoaVCS → 동기화 / 비교 | 푸시… | 차이 비교 (Diff) |
| MoaVCS → 이력 및 변경 | 로그 보기, 변경 사항 확인 | 로그 보기, 행별 이력 (Blame), 변경 사항 확인 |
| MoaVCS → 저장소 | MoaVCS에서 열기, 복제 / 체크아웃…, 여기에 저장소 만들기…, 원격 주소… | MoaVCS에서 열기, 원격 주소… |
| MoaVCS → 도구 | 설정… | 설정… |

표의 그룹 이름은 설명용이며, 하위 메뉴 안에서는 구분선으로 나눕니다. **…** 표시는 입력이나 확인이 필요한 작업입니다. **로그 보기**는 클릭한 파일·폴더가 속한 저장소 전체 이력입니다. Diff와 Blame은 설정한 내장 또는 외부 도구를 사용합니다. 탐색기 첫 메뉴에서 다른 앱 항목과의 상대적인 순서는 Windows가 결정합니다.

v0.8.1부터 각 작업에 전용 아이콘을 표시합니다. 커밋은 체크 표시, Pull·Push는 아래·위 화살표, Diff는 나란한 문서, 로그는 시계, Blame은 작성자와 행, 변경 확인은 목록, 열기는 폴더, 복제는 겹친 문서, 생성은 더하기가 있는 폴더, 원격 주소는 연결 고리, 설정은 톱니바퀴입니다. 첫 메뉴의 바로가기와 하위 메뉴에서 같은 아이콘을 사용합니다. MoaVCS 메뉴에는 브랜드 로고를 표시합니다.

**설정 → 탐색기**에서 **커밋을 첫 번째 메뉴에 표시**, **업데이트 / Pull을 첫 번째 메뉴에 표시 (폴더)**를 켜거나 끌 수 있습니다. 체크를 해제한 작업은 MoaVCS 하위 메뉴에 표시되며, 두 위치에 중복으로 나타나지 않습니다. **메뉴 등록 / 갱신**은 선택을 저장하고 바로 적용합니다. 현재 실행 중인 설치본의 메뉴가 등록되어 있다면 **설정 저장**으로 변경한 선택도 적용합니다. 설치 프로그램 역시 저장된 선택을 유지합니다.

커밋은 변경 목록과 메시지 입력 화면을 엽니다. 업데이트와 푸시는 저장소를 확인한 뒤 기존 확인창을 표시하며, 취소하면 실행하지 않습니다. Git 업데이트는 fast-forward만 허용합니다. SVN·Perforce처럼 해당 작업을 제공하지 않는 VCS에서는 미지원 안내를 표시합니다. 정적 메뉴이므로 저장소 종류·파일 상태별로 항목이 동적으로 숨겨지지는 않습니다.

복제 / 체크아웃은 원격 주소와 대상 폴더를 입력하는 대화상자를 엽니다. 클릭한 폴더는 폴더 탐색의 시작 위치로 사용하고 복제 대상은 비워 둡니다. **여기에 저장소 만들기…**는 선택한 폴더를 입력한 생성 대화상자를 엽니다. 실행 버튼을 누르기 전에는 폴더나 저장소를 만들지 않습니다. 설정은 저장소 감지 없이 바로 열립니다.

**원격 주소…**는 Git 저장소의 `origin` 주소를 표시합니다. **저장**을 눌러야 기본 fetch 주소를 변경하거나 origin을 추가합니다. 추가 fetch 주소·별도 push 주소는 유지하며, Pull·Push는 실행하지 않습니다. Git 이외의 제공자는 안내만 표시합니다. 상세한 지원 범위는 [원격 주소 설정](supported-vcs.md#원격-주소-설정)을 참고하세요.

## 등록 및 갱신

업데이트 설치 시 탐색기 메뉴 등록 옵션을 선택하거나 **설정 → 탐색기 → 메뉴 등록 / 갱신**을 누르세요. MoaVCS 소유 표시가 있는 메뉴만 새 구성으로 다시 등록하므로 구버전의 항목이 중복으로 남지 않습니다. 다른 설치본을 제거할 때에는 등록된 실행 파일 경로가 다르면 현재 메뉴를 보존합니다.

폴더 배경에는 현재 폴더를 위한 %V를, 폴더 및 파일에는 대상 경로인 %1을 전달합니다. 파일·폴더 선택 메뉴의 `MultiSelectModel`은 `Single`이며 다중 경로를 임의로 합쳐 실행하지 않습니다. 선택된 항목이 없는 폴더 배경 메뉴에는 이 제한을 적용하지 않습니다. v0.6.1 이하에서 배경 메뉴가 숨겨졌다면 업데이트 후 **메뉴 등록 / 갱신**을 눌러 기존 등록을 교체하세요.

등록·갱신·제거 후에는 Windows Shell에 변경 알림을 보내 메뉴 캐시를 갱신합니다. 열려 있던 우클릭 메뉴는 닫고 다시 여세요.

아이콘 파일은 설치 폴더의 `icons\explorer`에 포함됩니다. 포터블 앱을 옮길 때는 이 폴더도 함께 옮긴 뒤 새 위치에서 **메뉴 등록 / 갱신**을 실행하세요. 아이콘에는 16·20·24·32·40·48·64·256 픽셀 이미지가 들어 있어 화면 배율에 맞는 크기로 표시할 수 있습니다.

끝이 역슬래시인 경로가 Windows 명령행에서 닫는 따옴표를 이스케이프하지 않도록, 셸 인수 끝에 Windows 파일 이름에서 사용할 수 없는 | 표시를 덧붙입니다. 앱이 이 표시를 제거한 뒤 경로를 처리합니다.

Windows 11의 새 컨텍스트 메뉴는 앱 아이덴티티를 가진 패키지형 앱이 추가 확장 지점을 사용하도록 설계되어 있습니다. 이 앱은 현재 비패키지 WPF 데스크톱 앱이므로 Windows 11에서는 정적 레지스트리 메뉴가 더 많은 옵션 표시 아래에 나타날 수 있습니다. 새 메뉴에 표시하려면 나중에 MSIX 패키지와 IExplorerCommand 구현을 추가해야 합니다.
